### 1.2 생성된 문서

  - 각 API의 HTTP 메서드, 경로, 파라미터, 요청/응답 형식
  - 공통 헤더 및 쿼리 파라미터

### 1.3 주요 API 카테고리

| 카테고리 | 설명 | 주요 엔드포인트 |
|----------|------|----------------|
| 위치 (Locations) | 지역 정보 조회 | `/locations`, `/locations/carmore` |
| 제휴사 (Affiliates) | 렌터카 업체 정보 | `/affiliates`, `/affiliates/{id}` |
| 차량 (Cars) | 차량 검색/상세 | `/cars`, `/cars/models`, `/cars/detail/{id}` |
| 예약 (Reservation) | 예약 CRUD | `/reservation/reservations`, `/reservation/pre-reservation` |
| **리뷰 (Reviews)** | 지점별 리뷰 조회 | `/reviews/{affiliateBranchIndex}` |
| 관리자 (Admin) | 지점/업체/위치 관리 | `/admin/branch/*`, `/admin/company/*` |

### 1.4 리뷰 API 상세 (프로젝트 핵심)

```
GET /reviews/{affiliateBranchIndex}
```

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `affiliateBranchIndex` | number | 필수 | 제휴사 지점 인덱스 (Path) |
| `type` | string | 필수 | 리뷰 타입 |
| `page` | number | 선택 | 페이지 번호 |
| `pageSize` | number | 선택 | 페이지당 항목 수 |
| `order` | string | 선택 | 정렬 순서 |
| `rentType` | string | 선택 | 렌트 타입 |

## 6. 참고 코드

### 6.1 API에서 제휴사 정보 가져오기

```python
import requests
import pandas as pd

# API 호출
url = "https://dev-rentcar-api.carmore.kr/affiliates?locationType=DOMESTIC"
response = requests.get(url)
data = response.json()

# 제휴사 목록 추출
affiliates = data.get('result', {}).get('affiliates', [])

# DataFrame 변환
affiliate_list = []
for aff in affiliates:
    location = aff.get('location', {}) or {}
    affiliate_list.append({
        '지점번호': int(aff.get('id')),
        '회사번호': int(aff.get('companyId')),
        '지점명': aff.get('name'),
        '주소': location.get('address'),
        '지역코드': location.get('locationCode'),
    })

api_df = pd.DataFrame(affiliate_list)
```

### 6.2 Excel 데이터와 매칭

```python
# Excel 로드
excel_df = pd.read_excel('data/리뷰리스트_20260109.xlsx')

# 고유 조합 추출
unique_combos = excel_df[['회사번호', '지점번호']].drop_duplicates()

# 매칭
merged = unique_combos.merge(
    api_df,
    on=['회사번호', '지점번호'],
    how='left'
)

# 결과 저장
merged.to_excel('output/회사지점_매칭결과.xlsx', index=False)
```
