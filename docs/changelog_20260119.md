- `-`: 부정
- `0`: 중립

### 2.1 이중부정 패턴 추가 (DOUBLE_NEGATION_PATTERNS)

부정어 + 없다/못하다 = **긍정**으로 처리

```python
DOUBLE_NEGATION_PATTERNS = [
    r'불편.{0,5}없',      # 불편함이 없다
    r'불만.{0,15}없',     # 불만이라고 할 부분없다
    r'문제.{0,5}없',      # 문제가 없다
    r'걱정.{0,5}없',      # 걱정이 없다
    r'부족.{0,5}없',      # 부족함이 없다
    r'아쉬.{0,5}없',      # 아쉬움이 없다
    r'불편.{0,10}못',     # 불편함을 느끼지 못했다
    r'불만.{0,10}못',     # 불만을 느끼지 못했다
    ...
]
```

**적용 예시:**
| 입력 | 이전 | 현재 |
|-----|-----|-----|
| "불편함이 없었습니다" | 차량상태(-) | 차량상태(+) |
| "딱히 불만이라고 할 부분없습니다" | 고객응대(-) | 고객응대(+) |

### 2.2 긍정 예외 패턴 추가 (POSITIVE_EXCEPTIONS)

부정 패턴에 매칭되지만 실제로는 긍정인 표현

```python
POSITIVE_EXCEPTIONS = [
    # 기존
    '틀림없', '끄떡없', '변함없', '손색없', ...

    # 신규 추가
    '편안',             # 편안하다 (안\s*하 오탐 방지)
    '만안',             # 만안구 (지명)
    '생각하지 못한',    # 누구도 생각하지 못한 (긍정 맥락)
    '상상하지 못한',    # 상상하지 못한
    '기대하지 못한',    # 기대하지 못한
]
```

**적용 예시:**
| 입력 | 이전 | 현재 |
|-----|-----|-----|
| "편안하게 잘타고 반납했습니다" | 고객응대(-) | 고객응대(+) |
| "누구도 생각하지 못한 세심한 서비스" | 고객응대(-) | 고객응대(+) |

### 2.3 부정 패턴 확장 (NEGATIVE_PATTERNS)

신규 추가된 패턴:

```python
# 구어체/신조어
r'드러웠',     # 드러웠 (더러웠의 구어체)
r'드러워',     # 드러워
r'쩔어',       # 쩔어 (담배에 쩔어)
r'덜덜',       # 덜덜 (차가 덜덜거려)

# 상태 표현
r'이상해',     # 이상해 (브레이크 이상해)
r'이상하',     # 이상하다
r'나빠',       # 나빠 (기분 나빠)

# 가격 관련
r'호구',       # 호구
r'호갱',       # 호갱

# 복합 패턴
r'기분.{0,5}안',    # 기분 안좋
r'기분.{0,5}나빠',  # 기분 나빠
r'안\s*좋',         # 안 좋 (공백 포함)
```

### 2.4 부정 패턴 수정 (오탐 방지)

```python
# 이전: "편안하게"의 "안하"에 매칭됨
r'안\s*하'

# 수정: 한글 뒤에 오는 "안하"는 제외
r'(?:^|[^가-힣])안\s*하'
```
